### &nbsp;Operating principles

<br/>

<pre>
  01   if it is featured, the code is real and you can inspect it.
  02   test the actual flow, not the happy path.
  03   prefer something visible over something described.
  04   ship the smallest version that genuinely works.
  05   no demo data pretending to be a product.
</pre>
