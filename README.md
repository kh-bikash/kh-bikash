<br/>

<div align="center">

  A[Public repo] --> B[Parse README + code]
  B --> C[LLM writes the script]
  C --> D[faster-whisper aligns audio]
  D --> E[Remotion renders scenes]
  E --> F[Captions burned in]
  F --> G[.mp4 explainer]
  G --> H[You watch it]
