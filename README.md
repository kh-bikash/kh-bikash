### 🧊 ReflexCube v2 — *Flagship Project*
> **Prompt-Driven Modular AI Systems & 3D Intelligence Platform**

[![TypeScript](https://img.shields.io/badge/TypeScript-75.9%25-3178C6?style=flat-square&logo=typescript&logoColor=white)](https://github.com/kh-bikash/Reflex-Cube)
[![Python](https://img.shields.io/badge/Python-22.2%25-3776AB?style=flat-square&logo=python&logoColor=white)](https://github.com/kh-bikash/Reflex-Cube)
[![Stars](https://img.shields.io/github/stars/kh-bikash/Reflex-Cube?style=flat-square&color=39d353&labelColor=0d1117)](https://github.com/kh-bikash/Reflex-Cube)
[![Repo](https://img.shields.io/badge/View%20Repository-0d1117?style=flat-square&logo=github&logoColor=white)](https://github.com/kh-bikash/Reflex-Cube)

ReflexCube v2 is a production-architecture AI platform where users describe an AI model in plain English — and the system **trains it, streams live logs, and deploys it**, all visualized through an immersive 3D interface. It's the infrastructure layer built for researchers, startups, and data scientists who need a serious interface for rigorous AI workflows.

<table>
<tr>
<td width="50%" valign="top">

**🏗️ Backend Architecture**

- **Cube Architecture** — 15 isolated, async AI agents scoped to distinct domains
- **FastAPI Gateway** — ThreadPool routing, zero GIL lockup via `subprocess.Popen` isolated workers
- **Real-Time SSE Streaming** — Live training logs pushed to terminal UI via Server-Sent Events
- **End-to-End Pipeline** — Train → Predict → Download `.pt` models as `.zip` via REST
- **SQLite Persistence** — `reflex.db` via SQLAlchemy for job state & inference history
- **Git LFS** — Serialized `.pt` tensor models versioned at scale

</td>
<td width="50%" valign="top">

**🎨 Frontend Engineering**

- **3D Canvas** — React Three Fiber with interactive Cube visualization & WebGL
- **Animation Layer** — Framer Motion + GSAP + Lenis smooth scrolling
- **State Management** — Valtio atomic state + TanStack React Query
- **UI System** — Shadcn UI (Radix primitives) + TailwindCSS
- **Data Visualization** — Recharts dashboards for inference metrics
- **Build Tooling** — Vite + TypeScript strict mode

</td>
</tr>
</table>

**API Surface:**
```
POST   /api/models/create              →  Spawns isolated training subprocess, returns job_id
GET    /api/training/status/{job_id}   →  Polls SQLite for compilation progress
GET    /api/logs/{job_id}              →  SSE stream: live JSONL stdout from training worker
POST   /api/models/{job_id}/predict    →  Loads compiled HuggingFace pipeline, runs inference
GET    /api/models/download/{job_id}   →  Packages .pt tensors → .zip for download
POST   /api/cubes/run                  →  Executes command against a named Cube agent
```

```python
class ReflexCubeArchitecture:
    """
    End-to-end AI model lifecycle in one platform — built from scratch.
    """
    def prompt_to_model(self, user_prompt: str) -> DeployedModel:
        job     = self.api.create_model(prompt=user_prompt)       # POST /api/models/create
        logs    = self.sse.stream(job_id=job.id)                  # Real-time SSE training logs
        model   = self.trainer.compile(job_id=job.id)             # HuggingFace pipeline
        package = self.api.download(job_id=job.id)                # .pt tensors → .zip
        return self.cube_registry.deploy(model, cube_id="custom") # Live 3D visualization

    cubes_online : int       = 15
    next_upgrade : str       = "LoRA fine-tuning + Milvus vector DB + Cube Marketplace"
    agents       : list[str] = ["Talent", "Nexus", "Legal", "Alpha", "Career",
                                 "Brand", "FitPal", "Travel", "Sentinel", "Ledger",
                                 "Forge", "Vision", "Dream", "Lens", "Chef"]
```
